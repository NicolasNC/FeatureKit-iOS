# Changelog

All notable changes to the FeatureKit iOS SDK distribution will be documented in this file.

## Unreleased

- Simplified SDK configuration so customers only provide the FeatureKit API key.
- The SDK now derives the host application's Bundle ID from `Bundle.main.bundleIdentifier` instead of accepting a caller-supplied Bundle ID.
- Documented server-side API key and Bundle ID authorization behavior.
- Added Simplified Chinese integration documentation.

## 1.0.0

- Initial binary SDK distribution.
- Swift Package Manager integration.
- CocoaPods binary integration metadata.
- Manual XCFramework integration.
- iOS 15+ support.
